# LogiOps 桌面客户端 · 安装说明

> 版本 0.1.0 ｜ Windows 10/11 64 位 ｜ 安装包约 107 MB

## 一、要拷到别的电脑的文件

**只需要一个文件**：

```
LogiOps-Setup-0.1.0.exe
```

拷到 U 盘 / 微信 / 网盘，在目标电脑上双击安装即可（不需要安装 Node、Python、Docker 等任何环境）。

## 二、安装步骤

1. 双击 `LogiOps-Setup-0.1.0.exe`
2. 如果 Windows 弹出 **SmartScreen**（"Windows 已保护你的电脑"）：
   → 点 **「更多信息」** → **「仍要运行」**
   （原因：安装包没有购买代码签名证书。生产环境应买证书，见 `docs/10-云服务器部署.md`）
3. **选择安装位置**：
   - 建议用 **默认**：`C:\Users\<你的用户名>\AppData\Local\Programs\LogiOps`
     —— 不需要管理员权限，也不会遇到目录权限问题；
   - 也可以换成别的**普通目录**。
     ⚠️ 不要装到"以前被管理员权限安装过、且现在普通权限写不进"的目录（会报"不能打开要写入的文件"）
4. 装完 **不会自动启动**（这是刻意的：自动启动会导致"下次安装时程序还在运行、装不上"）
   → 从 **桌面 / 开始菜单** 的 **LogiOps** 打开

## 三、首次打开前确认两件事

| 事项 | 说明 |
|---|---|
| **软件要联网** | 默认连 `http://101.200.139.115`（你的云服务器），服务器实例需要在开机状态 |
| **登录账号** | `owner@logiops.dev`（还有 admin / operator / viewer），口令是服务器 `.env` 里的 `DEMO_PASSWORD` |

想换服务器地址：菜单 **服务器 → 设置服务器地址…**（快捷键 `Ctrl+,`），保存后自动重新加载。

## 四、多人协同怎么用

- **所有电脑填同一个服务器地址** → 看到的就是**同一份数据**（客户端只是壳，数据在服务端）
- 新同事的账号：先自己**注册**（会得到他自己的空工作区）→ 管理员在 **成员管理** 里按邮箱把他加进来并分配角色
  （OWNER / ADMIN / OPERATOR / VIEWER，权限逐级递减）
- 并发保护：同一张单子两人同时改，后提交的会收到"数据已被他人更新"并自动刷新（乐观锁）

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 安装到一半提示 **「LogiOps 无法关闭」** | 先退出正在运行的 LogiOps（任务管理器 → **「详细信息」**标签页 → `LogiOps.exe` → 结束任务），再点 **「重试」** |
| 提示 **「不能打开要写入的文件：…\Uninstall LogiOps.exe」** | 安装目录权限问题 → 换成默认安装位置重装 |
| 火绒 / 联想管家报**木马** | 未签名程序的常见误报 → 把安装目录加入**信任区**；根治办法是买代码签名证书 |
| 双击没反应 / 界面白屏 | 看日志：`%APPDATA%\LogiOps\boot.log`、`%APPDATA%\LogiOps\startup.log`；菜单 **帮助 → 保存界面截图…** 可导出界面截图 |
| 界面能开但没数据 | 服务器没开或地址填错 → 菜单 **服务器 → 检测后端连接** |

## 六、以后怎么更新

后端改动：不用管客户端（服务器上更新即可，刷新就生效）。
前端改动：默认是"远端优先"——**只更新服务器，客户端刷新即最新**。
外壳改动（图标/菜单/发布模式）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build-desktop.ps1   # 重新打包
```

然后拿新的 `LogiOps-Setup-<版本>.exe` 重新安装（会覆盖旧版本、保留你的配置）。

## 七、软件在哪里放数据

| 内容 | 位置 |
|---|---|
| 服务器地址等配置 | `%APPDATA%\LogiOps\config.json` |
| 启动日志 | `%APPDATA%\LogiOps\boot.log` |
| 业务日志 | `%APPDATA%\LogiOps\startup.log` |
| 页面缓存（远端优先模式） | `%APPDATA%\LogiOps\webcache\` |
| **业务数据** | **在云服务器上**（MySQL），不在本机 —— 所以多台电脑看到的是同一份数据 |
