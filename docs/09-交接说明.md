## 2. 当前业务口径（用户亲口定的，别按旧文档改回去）

### 2.1 风险模型：**一张异常单只受一个问题影响**
| 问题类型 | 分数 | SLA 影响 |
|---|---|---|
| **车辆故障单** `VEHICLE_BREAKDOWN` | 车辆故障 **1** + 客户等级（VIP **1** / SVIP **2**）= 1~3 | **完全没有**：详情页不显示 SLA 卡；列表「SLA 影响」显示「—」；`sla_delay_minutes=None`、`sla_breached=False` |
| **延误单** `DELAY_RISK` | 延误档位（≤120=1 / 121–360=2 / >360=3）+ 客户等级，封顶 4（**不再重复加"违约 1"**） | 有：SLA 卡内容 = **承诺到达 / 实际送达 / 延误时长** |

- 等级：0→LOW，1–2→MEDIUM，3→HIGH，≥4→CRITICAL（`MAX_SCORE=4`）。**未结束的异常最低 MEDIUM**；LOW/0 只出现在"已结束"的**当前风险**里。
- 因子代码：车辆单 = `VEHICLE_BREAKDOWN`(+客户等级)；延误单 = `DELAY_BASE`(+客户等级)。旧的 `SLA_BREACH` 因子已取消。

### 2.2 建单时机
- **在途不报延误**：检测规则只剩 `STALL_OVER_THRESHOLD`（轨迹停滞 ≥120min → 车辆故障单）。旧的 `ETA_BREACH_SLA` 已下线（枚举保留仅供历史数据读取）。
- **延误只在送达时判定**：订单点「送达」→ 先按现有规则把送达那刻还开着的单收口（处理中→已解决；待确认→已关闭），再用 `实际送达 − 承诺送达 > 规则允许延迟` 判定；**超了才自动建延误单**（`status=DETECTED`、`detected_by=SYSTEM`、`detection_rule=DELIVERED_BREACH`）；没超**不建单**。

### 2.3 修改功能（替代旧的"录入延误"）
- 入口：① 订单详情页「修正实际送达时间」（订单已送达时显示，需 `order.manage`）；② 异常详情页 SLA 卡的「修改」。
- 接口：`PATCH /api/v1/orders/{id}/delivered-at`，body `{delivered_at, note?}`；未送达 → 409；早于派车 → 422；OPERATOR → 403。写审计 `order.delivered_at_corrected`。
- 改完立即重算：仍违约 → 重算延误/分数并写 `ETA_UPDATED`；**不再违约 → 自动收口**（处理中 → `RESOLVED`；**待确认 → `CLOSED(reason_code=INVALID)`**，状态机只允许这两个出口）。
- 旧的「录入延误」已删除：路由 `POST /exceptions/{id}/delay`、`ExceptionDelay`、`ExceptionCreate.delay_minutes`、`set_delay`/`_apply_manual_delay` 全部移除。

### 2.4 其它已定口径（早前几轮）
- **异常状态只有 4 个**：待确认 `DETECTED` → 处理中 `PROCESSING` → 已解决 `RESOLVED` → 已关闭 `CLOSED`（`CONFIRMING` 并入处理中；`ANALYZING` 随 AI 停用废弃；旧值读取时归一显示为「处理中」）。
- **`type` vs `current_type`**：`type` = 建单原因（历史，不变）；`current_type` = **当前问题**（未结束的单按风险因子实时推导；已结束的单沿用建单原因）。界面一律显示 `current_type`。
- **`level/risk_score` vs `current_level/current_risk_score`**：后者是**当前风险**，已解决/已关闭 → `LOW/0`；前者是历史存档，详情页「风险等级（历史判定）」卡片用。
- **手工建单不选异常类型**（订单页 + 异常中心都去掉了类型选择；不传 `type` 时后端按订单现场推）。
- **异常列表不显示"异常类型"列**；「等级」列显示当前风险（已结束 → 灰「无风险 · 0 分」）。
- **车辆已修复 = 信号级闭环**：订单时间线录「维修完成（REPAIR_END）」→ 车辆回在途 → 读取时自动移除「车辆故障」因子（无需点击）；或一键「车辆已修复」（异常页/订单页），异常单继续存在。
- 留痕顺序（修过的 bug）：`resolve/close/force_status` **先留档结束那一刻的风险快照，再释放车辆**（否则已结束卡片的"历史判定"会被刷成空因子/LOW 0 分）。
- 时钟默认**真实时间**（`CLOCK_MODE=system`），演示页可运行时切「虚拟时钟」；真实时间下 `tick`/`set-clock` 返回 409。
- AI（`AI_ENABLED=false`）与 ETA 速度模拟（`ETA_ENABLED=false`）**已停用、代码保留**。
