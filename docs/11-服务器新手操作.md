# 11 · 服务器新手操作手册（第一次用服务器）

> 面向：**第一次**用 Linux 云服务器的人。命令都能直接照抄。
> 你的机器：阿里云 ECS，镜像 **Ubuntu 24.04**（2 核 2G / 40G ESSD）→ 装软件用 **`apt`**，防火墙主体是 **安全组**（`ufw` 通常没启用）。
> ⚠️ 前提：实例必须**已分配公网 IP**（阿里云控制台 → 实例 → 「分配公网 IP」或绑定 EIP），否则从家里连不上（只有私网 IP 是进不去的）；不想分配也可以先点控制台的「**远程连接**」在浏览器里进系统。

---

## 0. 先把概念摆正（30 秒）

- 云服务器 = 一台**放在机房里的 Linux 电脑**，你没有显示器键盘，只能通过网络"打字"指挥它。
- 你打字用的那个窗口叫**终端**（Windows 上就是 PowerShell / Windows Terminal）。
- 你和服务器之间用 **SSH** 通信：一条加密的"远程命令行"。
- 你在自己电脑上打的命令，是在**你的电脑**上执行；连上服务器后打的命令，是在**服务器**上执行 —— 看提示符区分（见 §2）。

---

## 1. 连上去（第一步）

### 1.1 打开终端（在你的 Windows 上）

- 按 `Win + X` → 选「**终端**」或「**Windows PowerShell**」；或开始菜单搜 `PowerShell`。

### 1.2 输入连接命令

```powershell
ssh root@<你的公网IP>
```
- 登录名不是你设的？阿里云购买时让你选过「登录名」：可能是 `root`，也可能是 `ecs-user`（那命令就写 `ssh ecs-user@IP`）。
- 第一次连会问：
  ```
  The authenticity of host '...' can't be established.
  ... Are you sure you want to continue connecting (yes/no/[fingerprint])?
  ```
  → 输入 **`yes`** 回车（这是一次性的，以后不再问）。
- 然后提示 `password:` → 输入你购买时设的密码。
  ⚠️ **输入密码时屏幕上不显示任何字符**（连 `*` 都没有），这是正常的，敲完直接回车。
- 如果想用密钥登录（更安全，以后再说）：`ssh -i 私钥文件 root@IP`。

### 1.3 成功的标志 / 失败的样子

| 看到什么 | 意思 |
|---|---|
| `[root@iZbp1xxxxxxx ~]#` | ✅ 连上了（`#` = 管理员） |
| `[ecs-user@iZ... ~]$` | ✅ 连上了（`$` = 普通用户） |
| `Permission denied (publickey,password)` | ❌ 密码或登录名不对 |
| `Connection timed out` | ❌ 安全组没放通 22，或 IP 写错 |
| `Connection refused` | ❌ 服务器上 SSH 服务没跑（少见） |

### 1.4 复制粘贴 & 退出

- **粘贴**：在 Windows Terminal / PowerShell 里 **右键**（或 `Ctrl + Shift + V`）。**`Ctrl + V` 在这里无效**。
- **复制**：选中文字后 `Ctrl + C` 或右键菜单。
- **退出登录**：`exit`（回到你自己的电脑）。

## 2. 看懂那一行提示符

```
[root@iZbp1a2b3c4 ~]#  ls
 └A┘ └────B────┘ └C┘ └D┘
```
- **A** 当前用户：`root` = 超级管理员；`ecs-user` = 普通用户（改系统要加 `sudo`）
- **B** 服务器主机名（每台不一样）
- **C** 当前所在目录：`~` 表示"我的家目录"
- **D** `#` = 管理员提示符，`$` = 普通用户提示符

> 你打的每条命令都在"当前所在目录"里执行。**先 `pwd` 确认自己站在哪**，再动手删东西。

## 3. 高频命令速查（先照抄跑一遍）

| 想干什么 | 命令 | 备注 |
|---|---|---|
| 我在哪个目录 | `pwd` | |
| 看目录里有什么 | `ls` / `ls -l`（详细）/ `ls -a`（含隐藏文件） | |
| 进目录 / 回上一层 / 回家 | `cd /tmp` / `cd ..` / `cd ~` | 按 **Tab** 自动补全 |
| 看文件内容 | `cat 文件` / `less 文件`（按 `q` 退出） | |
| 建目录 | `mkdir ~/logiops`（`-p` 连父目录一起建） | |
| 复制 / 移动改名 | `cp 源 目标` / `mv 源 目标` | |
| 删除 | `rm 文件` / `rm -r 目录` | ⚠️ **没有回收站**，先 `ls` 确认 |
| 编辑文本文件 | `nano 文件` → 改 → `Ctrl+O` 回车保存 → `Ctrl+X` 退出 | 新手首选；没有就先装 `sudo dnf install -y nano` |
| 看磁盘 / 内存 | `df -h` / `free -h` | |
| 看进程 / 退出 | `top`（按 `q` 退出） | |
| 看端口占用 | `ss -lntp` | 例：`ss -lntp \| grep :80` |
| 中断卡住的命令 | `Ctrl + C` | 最常用！ |
| 翻历史命令 | `↑` / `↓` | |
| 查帮助 | `命令 --help`；`man 命令`（`q` 退出） | |

### 3.1 `sudo` 是什么

- 普通用户（`ecs-user`）想装软件、改系统配置，要在命令前加 `sudo`：
  ```bash
  sudo dnf install -y nano
  ```
  第一次会要求你输**自己的登录密码**（同样不显示）。
- 如果你登录的就是 `root`，不用加 `sudo`（但权力大、更危险，见 §7）。

### 3.2 你这台机器怎么装软件（Ubuntu 24.04）

```bash
apt --version                       # 有 apt 就对了
sudo apt update                     # 刷新软件源索引（第一次慢一点）
sudo apt install -y nano tmux curl git
```
> 跟 CentOS/RHEL 一路的机器（`dnf`/`yum`）不一样，别混着抄。

### 3.3 防火墙

```bash
sudo ufw status                     # 看防火墙状态（阿里云 Ubuntu 镜像通常是 inactive）
```
- 阿里云的**安全组**是主要关口（你在控制台配的那个）。
- `ufw` 如果是 `active`，还要在里面放行端口：
  ```bash
  sudo ufw allow 22/tcp && sudo ufw allow 80/tcp
  ```
- 如果是 `inactive`，不用管它，只配安全组即可。

## 4. 练手三件事（都在 /tmp 里做，随便折腾）

```bash
pwd                     # 我在哪
cd /tmp                 # 进临时目录（重启会清空，适合练手）
mkdir hello && cd hello # 建目录并进去
echo "hello server" > a.txt   # 写一个文件
cat a.txt                     # 看内容
nano a.txt                    # 编辑：改字 → Ctrl+O 回车 → Ctrl+X
ls -l                         # 看文件与权限
cd .. && rm -rf /tmp/hello    # 清掉练习目录（先 cd 出去再删）
```
> 以后改 `.env` 就是这个操作（`nano .env`）。

## 5. 长任务别用"裸 SSH"跑（部署时最关键的一招）

**问题**：你直接在终端里跑一个 5 分钟的任务，如果网络抖一下 / 笔记本休眠 → SSH 断开 → **命令被杀掉**，构建白跑。

**办法 A（推荐）：tmux**（一个"不会断的会话"）

```bash
sudo apt install -y tmux
tmux new -s work          # 新建会话，名字叫 work
# ……在里面干活（比如 docker compose up -d --build）……
# 临时离开：按 Ctrl+B 松开，再按 D（detach）—— 任务继续跑
tmux ls                   # 看有哪些会话
tmux attach -t work       # 回来接着看（或 tmux a）
exit                      # 会话说：里面的任务结束后输 exit 关闭会话
```

**办法 B（土办法）：后台跑 + 输出写日志**

```bash
nohup 你的命令 > out.log 2>&1 &
tail -f out.log           # 实时看输出，Ctrl+C 只退出查看、不杀任务
```

## 6. 看状态/看日志（部署后会天天用）

```bash
ss -lntp | grep :80              # 80 端口有没有人在听
curl -I http://127.0.0.1         # 在服务器上"自己访问自己"
systemctl status docker          # 看某个系统服务状态
systemctl restart docker         # 重启服务
tail -f /var/log/xxx.log         # 实时看日志
journalctl -u docker -n 50       # 看服务最近 50 行日志
```

**关机 / 重启**（谨慎）：
```bash
sudo reboot          # 重启（约 1 分钟，SSH 会断，稍后再连）
sudo poweroff        # 关机（控制台可以再开机；注意公网 IP 可能变）
```

## 7. 新手安全三铁律

1. **`rm -rf` 是唯一能瞬间毁掉整台机器的命令**：执行前先 `pwd` + `ls` 看清位置；能用绝对路径就别用变量拼。
   （常见事故：`rm -rf / tmp` 里多了个空格 → 删根目录。）
2. **不要把自己的密码/私钥发到任何地方**；含密钥的文件只给自己读：
   ```bash
   chmod 600 .env      # 只有文件主人能读写
   ls -l .env          # 看到 -rw------- 就对了
   ```
3. **别在没备份的情况下改 SSH 配置**（`/etc/ssh/sshd_config`）；万一把自己关在门外，用控制台的「**远程连接 / VNC**」进系统救回来。

---

## 8. 卡住时的自救顺序

1. 命令卡住不动 → `Ctrl + C`。
2. 报错原文别丢掉：**复制"你敲的命令 + 完整报错"**发给我。
3. 连不上服务器 → 阿里云控制台 → 实例 → 「远程连接」/「VNC」。
4. 不知道命令咋用 → `命令 --help`，或直接问我。
5. 想确认自己在哪、是什么用户 → `pwd; whoami; id`。
